# Venkat Repaka - Personal Portfolio
This is to showcase my portfolio to the world. A personal portfolio website presenting my background, skills, and
projects to internship reviewers and other professional contacts. Built from the vCard Personal Portfolio template and customized with AI-assisted editing

## Features
- Responsive single-page layout (desktop and mobile)
- About, Skills, Projects, and Contact sections
- Two featured projects with descriptions and links

## Built with
- HTML5, CSS3, JavaScript
- Static content only
- Customized with AI-assisted editing (see `ai-log.md` for the prompts, plan, and review notes)

## Project structure
```text
.
├── index.html          # Main page (identity, skills, projects, contact)
├── assets/
│   ├── css/style.css   # Styling (template defaults, minor edits only)
│   ├── img/            # Images (placeholder profile graphic, etc.)
│   └── js/             # Template scripts (unmodified)
├── content-notes.md    # Source content used to personalize the site
├── ai-log.md           # AI prompts, plan, and implementation log
└── README.md
```

## Running locally
No build step required — it's a static site.

## Content
All identity and project content is fictitious, created for this for sake of learning. No private or real personal information is published on this site.
